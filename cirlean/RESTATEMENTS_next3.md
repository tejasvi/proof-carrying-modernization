# cirlean next3: restatements and proof-script changes

## 1. Specification statements (FH: the cJSON harness)
None. The FH specification modules are the ones next2 used, byte for byte: CJPrintN, PrintSpecsN v2, CycleSpecsP2N
v4 (scratch/specN src_v4, checked by chain_next3_v2.sh against its sha256 before every chain build). The 10 bundle
sources are byte-identical to their latest deliveries (7 e6ac99a deliveries, 3 next2 v4 deliveries); each bundle's
theorem statements are therefore unchanged, and each bundle's SpecCheck module checks them against the specs.

## 2. Proof-script changes (statements unchanged)
All of them are in the FH chain's tactic and lemma sources (strong/chain_c4ef58d/src); the pin's chain is
scratch/unionact/chain_src_pin_v1 (diff against chain_c4ef58d/src: chain_pin_v1.diff; the freeze notice gives its
full sha256 and the tree hash chain_next3_v2.sh records in chain_src.sha256).
- (a) vcgspeed's chain_rt_v3 (GhostNat7, GhostNat8, GhostNat12): the drivers cir_run8 and cir_run12 state the type
  facts `cirR_rt : ∀ j, ts[j].rt = .record "cJSON"` from CJ.forestPrintable on entry and clear them on exit, and
  pa_inst_terms skips the cirR_ hypotheses (so they never become global rewrite rules). With cirlean's fhrt2 simprocs
  these facts decide the exact type tests of typed and member accesses at item blocks; the symbolic state is never
  rewritten, so the closers still see CJ.rt.
- (b) pobj's budget line (GhostNat12.lean, the per-step heartbeat budget of cir_run12 for `.holds` steps):
  3000000 → 6000000 (and the docstring above it). print_object's `output_buffer->offset += depth` store needs about
  4.4M heartbeats after next3's per-access union-view decision; the primary fix (the union guard decided from the type
  and path, as a match on Ctx.unionOnPath) brought print_object from 81 errors to 8 but left this step over 3M.
  Agreed before use by the harness-study session (the FH theorems' owner) and the evidence-owner session under five conditions: statements byte-identical; old and
  new values here; standard axioms only; per-module and --fresh leanchecker replay under a 32 GiB address-space cap.
- The declarations whose proofs run cir_run12: listed in the freeze notice (every theorem of the modules that call it,
  with the sha256 of each source file against its delivery).
- maxHeartbeats: unchanged in every bundle (the fallback agreed for parse_array/parse_object was not needed). The
  6-case closer agreed in principle for parse_array was not needed either (unless the freeze notice says otherwise).
