# Bit-fields whose storage unit is an array (bitfields.cpp): !cir.array<!u8i x N> units, bits numbered
# little-endian across the bytes; reads sign- or zero-extend, writes keep the other bits. Also bool bit-fields and
# unions with tail padding (bitfields.cpp), volatile accesses and a zero-width bit-field (bitfforms.cpp). Each case
# is labelled with its expected outcome on the line above it: MATCH, or UB from cirrun where the standard leaves the
# value undefined (a field whose unit was never written), and where a union member reads bytes that the active member
# does not hold.
