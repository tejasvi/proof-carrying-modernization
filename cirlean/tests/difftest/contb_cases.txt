# Containers of containers from initializer lists, C++ null pointer arithmetic and std::vector::emplace_back
# (contb.cpp, contbc.c). An initializer_list's begin points to the first element of its backing array (the frontend
# stores &arr[0] where CIR stores the array's address); the modelled std::vector / std::string members also take
# the element at the address of an array of containers or of a byte view of one. In C++ a null pointer plus or
# minus 0 is null and two null pointers differ by 0; in C both are undefined (contbc.c). emplace_back of one
# element is push_back's path and returns a reference to it. Each case is labelled with its expected outcome on the
# line above it: MATCH, or UB from cirrun: null + 1 in C++ and the C cases (undefined), and two gaps, both defined
# in C++: g_emplace_convert and g_emplace_none (emplace_back with other arguments than one element). g_one_vec_list
# (a step past a one-element buffer, a lone heap object) was a third gap until bytes phase 1b closed it in next3.
