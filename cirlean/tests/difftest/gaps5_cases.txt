# The two-blocker programs of the static census: fputs and fwrite (BenchmarkGame fasta), ffs and ffsl (UnitTests
# 2005-05-11-Popcount-ffs-fls), ungetc and fscanf on stdin (McGill exptree), lrand48 and seed48 (McGill misr)
# (gaps5.c, a C source). Each case is labelled with its expected outcome on the line above it: MATCH, or UB from
# cirrun on the u_ cases (fwrite past the end of its object; a character pushed back onto stdin, not modelled).
# expect MATCH: fputs to stderr and stdout (glibc: 1)
gaps5 t_fputs 0
# expect MATCH: fwrite of 5 bytes to stderr
gaps5 t_fwrite 0
# expect MATCH: fwrite of 8 bytes to stderr
gaps5 t_fwrite 3
# expect MATCH: fwrite with size 0 or count 0
gaps5 t_fwrite_zero 0
# expect UB: fwrite past the end of the object
gaps5 u_fwrite_past 0
# expect MATCH: ffs of 0, 1, a power of two and INT_MIN
gaps5 t_ffs 0
# expect MATCH: ffs of 0, 1, a power of two and INT_MIN
gaps5 t_ffs 5
# expect MATCH: ffsl
gaps5 t_ffsl 0
# expect MATCH: ffsl
gaps5 t_ffsl 20
# expect MATCH: ungetc(EOF) on stdin fails (EOF), stdin still at its end
gaps5 t_ungetc_eof 0
# expect UB: a character pushed back onto stdin
gaps5 u_ungetc_char 0
# expect MATCH: fscanf on stdin: EOF, the object unchanged
gaps5 t_fscanf_stdin 0
# expect MATCH: lrand48 after seed48
gaps5 t_lrand48 0
# expect MATCH: lrand48 after seed48
gaps5 t_lrand48 9
# expect MATCH: seed48's copy of the previous state, then lrand48
gaps5 t_seed48_old 0
