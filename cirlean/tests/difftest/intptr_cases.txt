# Conversions between integers and pointers (intptr.c, a C source; intptrx.cpp, C++): flat addresses, as GCC
# and Clang convert (C11 6.3.2.3p5, p6, 7.20.1.4p1), and member function pointers, whose Itanium layout holds a
# function's address as an integer. Each case is labelled with its expected outcome on the line above it: MATCH;
# UB from cirrun (the native runs print GCC's result); MATCH (gap) where cirrun misses the UB; MISMATCH where the
# model differs from a native run by design. The UB cases are UB in C and C++ too: an access through a pointer
# that designates no object (the address of an object that has died, however it died; one past the end; outside
# the object), a relational comparison of pointers that designate no object (6.5.8p5), the conversion to an integer
# of a pointer to an object that has died (6.2.4p2), and a call through a null member function pointer.
