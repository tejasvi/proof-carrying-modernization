# Union activation by stores (unionact.cpp, C++; unionact_c.c, C): the member last stored is the active one,
# whichever pointer was used (C11 6.5.2.3p3, footnote 95); another member reads the stored bytes: a scalar of the
# same type at the same offset as it is, one of the same size reinterpreted, another composed from the bytes
# (6.5p7); the common initial sequence of structs may be read through either struct (6.5.2.3p6); a bit-field unit
# stored after another member keeps that member's bits; a member access of a const union writes nothing, and

# cirrun where C leaves the value undefined or unspecified, where the bytes read are not modelled (a NaN pattern),
