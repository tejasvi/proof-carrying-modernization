\section{Pre-registrations}
\label{app:prereg}

but had no pre-registration. The studies in the table below are pre-registered: a file with the procedure, the outcomes
and the analysis was frozen before the runs it governs, together with a SHA-256 manifest of its input files (samples,
commit lists, selection tools), and addenda fixed the samples and inputs left open by a file, each frozen before the
runs it governs. Later decisions went into an append-only deviation log, and each is reported where it affects a
number. For a run with \emph{inputs recorded}, the inputs and the tool commit were fixed and hashed before it started,
but no analysis was frozen. A result is \emph{exploratory} if it lies outside the migration study and every pre-registration and we logged it as such, with its date, in the deviation log, where such results are tagged ``labelled''. \section{Model settings}
\label{app:llm}


All model calls go to one commercial LLM through its API, in October 2026, with a fixed reasoning-effort setting and at
most 64,000 output tokens per call. Translation runs allow at most 10 attempts and \$15 each, with 60 fresh generated
cases per round and 300 for the final check, and seeds 1 to 3 for the input generator. The root-cause labels were produced by further calls with a fixed prompt, one per run in 30 of the 32 runs with behaviour
repairs; repairs that only fixed build failures were labelled from the build error, without a model call. In the security-fix and sample studies, the orchestrator uses the
same model for contracts, invariants and proof scripts, with three proposals per proof. The proofs of the migration
theorems were written by LLM agents and checked by Lean (Section~\ref{sec:effort}).
